把 **ProjectE（等价交换）的 EMC** 接进 **Beyond Dimensions（超越维度）的维度网络**。

**0.3.2 的主题是：让第三方模组看得见物化物品。**

0.3.0 把"你有 372 颗钻石"从一行字变成了网络里**真实的存储条目**。
但那些条目当时只有**本模组自己**看得见 —— 你把物流管道、存储总线接到网络上，
它们是看不见这些物品的，Create 的**蓝图大炮**也拿不到料。

0.3.2 打开了这道门：物化物品现在**能被第三方模组取用**，而且**取用照常扣 EMC**。

## 0.3.2 的主要变更

### 新增：Create 蓝图大炮能用上网络里的材料

把「蓝图接口」接到维度网络上之后，大炮现在能**看见并取用**网络里那些"用 EMC 换得出来的物品"：

- 大炮的物料清单里会出现这些物品，界面「已收集」也会如实计数；
- 真正施工取料时，**从网络 EMC 扣钱**、再把物品交给大炮（与手动兑换同一套价格）；
- 原理：超越维度的接口原本只对网络做**精确键查询**，物化条目的键类型不同、查不到；
  而大炮判定"这个槽有没有料"看的又是**模拟抽取**的返回值 —— 模拟说没有，真抽取那一步**永远不会发生**。
  本次补上了这两处（只补"看得见"和"模拟报量"，真抽取交付走的还是原路径，收费环节一行没改）。

### 新增：第三方物流管道 / 存储总线也能取用物化物品

这条**不依赖 Create**：任何通过"物品能力"读取网络的模组（AE2 / RS 的导入总线、
漏斗、机械臂等）现在都能看到物化物品。

- 网络原来对外的物品视图**只列举真实库存**，物化条目在另一个"桶"里，属于结构性不可见；
- 现在在该视图的**原有槽位之后**追加了一段"只读区"，把物化物品补进去；
  **原有槽位映射逐位不变**，不会串位。

### 变更：物化物品不再有额外说明行

以前物化物品的提示框里会多两行（"可兑换：N" 与"由网络 EMC 物化而来 —— 兑换会扣除 EMC"）。
现在**两行都去掉了**，它与普通物品在界面上完全一致（数量仍画在图标上）。

### 不变：收费红线

无论从哪条路取用物化物品，**一律先扣 EMC 再交付**：

- 模拟抽取（各种模组问"能抽多少"）**只读、不扣费**；
- 余额不足时**什么都不交付**，不"半份"；
- 价格口径与手动兑换**共用同一套算式**，所以不会出现"模组以为有 64 个、真取只给 1 个"。

## ⚠️ 已知取舍：自动化回路会静默损失 EMC

物化物品交给第三方之后，**不认识 EMC 的机器分不清**"这是 EMC 变出来的"还是"玩家真存进去的"。
如果搭一条「抽出 → 再插回同一网络」的回路，就会：

1. 抽出时按**购买价**扣 EMC；
2. 插回时按**回收价**折成 EMC。

而购买价 ≥ 回收价（两者之间的差额是 ProjectE 的固有设计）。
**每循环一次，网络 EMC 净减少这个差额，且没有任何提示。**

- **正常玩法不受影响**：按蓝图取料盖房子、把材料交给机器加工，都不是回路，没有损失。
- **单次损失**只有该物品的价差，与物化总量无关，**不会滚雪球**。
- 排查时优先怀疑：**会把物品又送回同一个网络的自动化**（回插漏斗、返回式管道等）。
- 量级参考：火药/钻石这类物品在实测环境里**购买价 = 回收价**，价差为 0，来回也不掉 EMC；
  有价差的物品请以自己环境的价格为准（界面上兑换价 = 购买价）。

> 这是"让物化物品真正可被自动化使用"的必然代价。完整分析见
> `docs/plan/CREATE-INTEGRATION.md` §5。若你希望彻底避免，可把 `materializeItems` 关掉回到 0.2 行为 ——
> 代价是界面里也不再显示可兑换数量。

## 安装

1. 安装 **NeoForge 21.1.194+**（推荐 `21.1.238+`，兼容较新的 JEI）
2. 把下面这些 jar 放进 `mods/`：
   - `beyondemc-1.21.1-neoforge-0.3.2.jar`（本 Release 的附件）
   - Beyond Dimensions
   - ProjectE
   - JEI（可选，想要配方填充就装）
   - Create（可选，想用蓝图大炮集成就装）
3. 启动游戏，在 **Mods** 列表里应能看到 "Beyond EMC"
4. 进入维度网络界面，先**存入一件东西**（让网络学会它），物化条目就会出现

服务端同理；本模组是 **BOTH** 端，客户端也要装。

## 从 0.3.1 升级

- **直接替换 jar**，不需要改配置、不需要动存档。
- 行为变化只有一处，且是"放宽"：**第三方模组现在能取用物化物品了**（上面「已知取舍」）。
  如果你不希望网络被自动化抽取，把 `config/beyondemc-server.toml` 里的
  `allowInterfaceWithdraw` 设为 `false`，或在自动化那侧不接网络。

## 从更早版本升级

- 从 **0.2.0** 上来：EMC 余额与学习集合原样保留，物化条目会自动生成；先看 `docs/release-notes-v0.3.1.md`。
- 从 **0.1.0** 上来：请先看 `docs/release-notes-v0.2.0.md` 里的**点击行为变化**。

## ⚠️ 卸载 / 回退前必读

**移除本模组会让所有维度网络里的 EMC 归零**（EMC 以自定义资源类型存在网络存储里，
超越维度对未注册类型会丢弃条目；存档不损坏，但那部分 EMC 会无声消失）。
**建议**卸载前先 `/beyondemc exchange <物品> <数量>` 把 EMC 换成物品取出。

**回退到 0.2.0 是安全的**（已实测）：拿 0.3 的存档去跑 0.2 的代码 —— 不崩、
EMC 与学习集合完整无损、物化条目被逐条 WARN 丢弃（会由 0.2 的虚拟条目照常显示）。
详见 `docs/testing/phase8-materialize-report.md`。

## 已验证到什么程度

**自动自检**（每次启动都会跑并写进日志；游戏内 `/beyondemc selftest` 可手动触发）：
本次新增一组 **`Create/第三方暴露` 6 项**断言（报价边界、报价与收费算式一致性 64 组、展示栈夹取、空入参、桶分离），
`Mixin 目标存活性` 核对目标由 7 个增至 **10 个，全部存在**。

**人工实测**（2026-10-01，真实客户端 + Create 6.0.10 + 真实 EMC 表）已确认：

- 门控与注入：日志 `Create Mixin 门控判定：create 在类路径上=true`，
  以及 `Create Mixin 已应用到 …NetedSchematicannonItemHandler` —— **Mixin 在真实环境成功注入，无注入失败**；
- 蓝图接口取料：日志 `接口兑换：minecraft:gunpowder ×1 → 扣除 192 EMC（单价 192）`
  —— **大炮取走网络里的火药，EMC 被实扣**（火药当时没有真实库存，走的就是物化路径）；
- 存档层面：`BDNet_0.dat` 中同时存在 **14 条** `beyondemc:stack_type/emc_item` 物化条目
  （数量互不相同、各自独立）与 `beyonddimensions:stack_type/item` 的**真实库存**
  （实测样本：装着 8 把附魔合金斧的潜影盒）—— 两类条目**分桶共存、不塌缩、不互相顶替**；
- 全程日志**无本模组相关的异常或注入错误**。

**尚未覆盖**：多人并发、AE2/RS 等具体物流模组上的取用实测（本模组的暴露层已在自检与
存档层面验证，但未在具体第三方管道上实跑）、10 万件量级的性能。

## 排查问题

游戏内运行：

```
/beyondemc selftest
```

物化 / 第三方集成相关的排查起点：

| 现象 | 先看 |
|---|---|
| 大炮不认网络里的材料 | 日志有无 `Create Mixin 已应用到 …`；没有则是 Create 未装或版本不符 |
| 管道看不到物化物品 | `/beyondemc materialize list` 是否有条目；`allowInterfaceWithdraw` 是否为 true |
| 界面里没有物化行 | 日志里 `EMC 表已就绪` 是否出现；条目需"已学习 + 买得起 + 无真实库存" |
| EMC 莫名其妙减少 | 是否有自动化在反复"抽出→插回"（见「已知取舍」）；对照 `[BeyondEMC] 接口兑换：` 日志频率 |
| 只想关掉它 | `materializeItems = false`（回到 0.2 行为），或 `allowInterfaceWithdraw = false` |
| 升级 BD/Create 后功能无声消失 | 日志里 `Mixin 目标存活性` 那一行（失配会逐条列出失效目标） |
