# BeyondEMC 项目资料库

> 本目录是"Minecraft 1.21.1 NeoForge 附属模组：把 EMC 接入超越维度的维度网络"项目的**全部工作资料**。
> 目标读者：接手实现的开发者（人或 AI）。**先读本文件**。

---

## 一句话需求

做一个 NeoForge 1.21.1 模组，依赖 **超越维度（Beyond Dimensions）** 与 **等价交换（ProjectE）**：

1. 在维度网络里**同步存储一个 EMC 数值池**；
2. 存入物品时，**有 EMC 值的物品自动折算成 EMC**（按回收价），并**自动并入网络的已学习集合**；
3. **无 EMC 值的物品按原逻辑存储**；
4. 在维度网络界面里**显示所有已学习物品**：有真实库存的显示库存数；无库存的显示"用网络 EMC 能兑换出的数量"，并且**可以直接点击、扣除 EMC 取出**。

## 已确认的产品决策（速查）

| 决策点 | 选择 |
|---|---|
| "已学习"的口径 | **网络级共享知识集合**（不是玩家个人 ProjectE 知识） |
| 存入折算价 | **回收价 `getSellValue`**（与 ProjectE 转换桌烧物品一致） |
| 取出兑换价 | **购买价 `getValue`**（因 `covalenceLoss ∈ [0.1,1.0]`，恒有 购买价 ≥ 回收价 → 不存在净收益路径。**默认 1.0 时两者相等，循环中性**） |
| 网络 EMC 与玩家个人 EMC | **完全独立**，互不转账 |
| 界面实现 | **Mixin 注入 BD 原生界面**（`DimensionsNetGUI` / `DimensionsNetMenu`） |
