把 **ProjectE（等价交换）的 EMC** 接进 **Beyond Dimensions（超越维度）的维度网络**。

0.2.0 带来两项改动：**兑换出的物品改为吸附到鼠标**（原版拾取手感），以及
**JEI 配方一键填充可以自动用网络 EMC 兑换材料**。

---

## ⚠️ 必需前置（三个 jar 必须同在 mods 目录里）

| 组件 | 版本要求 |
|---|---|
| Minecraft | `1.21.1` |
| NeoForge | `21.1.194` 或更高（开发与验证基线 `21.1.249`） |
| **Beyond Dimensions（超越维度）** | `0.7.30` 或更高 |
| **ProjectE（等价交换）** | `1.1.0` 或更高 |
| JEI（**可选**） | `19+`；若用较新的 JEI 构建，注意它自身可能要求更高的 NeoForge<br>（例如 JEI `19.44.0.401` 要求 NeoForge `21.1.238+`） |

**本模组不包含上述模组**，请自行下载后与本 jar 放进同一个 `mods/` 目录。
只放本模组会导致游戏拒绝加载并提示缺少依赖。

---

## 0.2.0 变更

### 变更：点击兑换改为吸附到鼠标（⚠️ 行为变化）

之前点击兑换，物品会**直接进入背包**。现在改为**像原版拾取一样吸附到鼠标**，
由你自己决定放到哪：

| 操作 | 效果 |
|---|---|
| **左键** | 换出**一组**（该物品的原版最大堆叠数）并**吸附到鼠标** |
| **右键** | 换出**一半**并吸附到鼠标 |
| **Shift + 左键** | **直接放进背包**（原版快捷移动语义，也是旧行为的去向） |

- 鼠标上已有**同类**物品 → 合并到堆叠上限，**只扣实际吸附数量**的 EMC
- 鼠标上拿着**别的**物品 → 拒绝并提示（不会交换、也不会把物品丢在地上）
- 余额不足 → 只吸附买得起的数量，**只扣那部分**

### 新增：JEI 配方填充自动用 EMC 兑换

装了 JEI 后，在维度网络的**合成菜单**里对任意配方点 JEI 的 `+`：
即使材料在网络里**没有库存**，只要网络已经学会它们、且 EMC 够，
材料会被**自动兑换**并填进合成栏 —— 相当于用 EMC 直接合成。

- 按**购买价 × 数量**扣费，与手动兑换同价；余额不足时只填能付得起的部分
- 想要的材料得**先存入过**（网络学会了才会被算作可用）
- **JEI 是可选依赖**：不装 JEI 时一切照常，只是没有这个集成

### 修复与健壮性

- 兑换的**身份一致性**收口（防"按普通物品价格铸造带组件物品"的刷物品漏洞）
- 背包满时**不会**扣了 EMC 却拿不到东西（对齐服务端的裁剪语义）
- 自检从 28 项扩充到 **38 项**，新增覆盖吸附容量规则与 JEI 可用量注入

## 安装

1. 安装 **NeoForge 21.1.194+**（推荐 21.1.238+，兼容较新的 JEI）
2. 把下面这些 jar 放进 `mods/`：
   - `beyondemc-1.21.1-neoforge-0.2.0.jar`（本 Release 的附件）
   - Beyond Dimensions
   - ProjectE
   - JEI（可选，想要配方填充就装）
3. 启动游戏，在 **Mods** 列表里应能看到 "Beyond EMC"

服务端同理；本模组是 **BOTH** 端，客户端也要装。

## 从 0.1.0 升级

- **直接替换 jar 即可**，存档与网络数据兼容（0.2.0 没有改动存档格式）
- 注意上面的**点击行为变化**：Shift+左键才是"直接进背包"

## ⚠️ 卸载前必读

**移除本模组会让所有维度网络里的 EMC 归零。**

因为 EMC 是以自定义资源类型存在网络存储里的，超越维度在反序列化时对未注册类型会静默丢弃条目
—— 存档不会损坏，但那部分 EMC 会无声消失。

**建议**：卸载前先用 `/beyondemc exchange <物品> <数量>` 把 EMC 换成物品取出。

## 排查问题

游戏内运行：

```
/beyondemc selftest
```

它会逐项检查存储层、折算钩子、读档守卫、兑换服务、策略配置、
**Mixin 目标存活性**（含 JEI 集成的注入点）、网络接口兑换、鼠标吸附、JEI 可用量，
并在日志里给出结论与原因。日志里带 `[BeyondEMC]` 前缀的行都是有意的诊断输出。

若 JEI 配方填充没反应，先看日志里有没有
`JEI Mixin 已应用到` 与 `JEI 转移钩子被调用` —— 这两行能把问题精确切成三层。
