把 **ProjectE（等价交换）的 EMC** 接进 **Beyond Dimensions（超越维度）的维度网络**。

0.3 的主题是：**让网络里的物品真的存在。**

以前界面里那行"你有 372 颗钻石"只是一行字 —— 拔掉 EMC 就没了，
物流管道看不见它，搜索也搜不到。现在它是网络存储里**一条真实的物品条目**，
由超越维度自己负责持久化与同步。

---

## ⚠️ 必需前置（三个 jar 必须同在 mods 目录里）

| 组件 | 版本要求 |
|---|---|
| Minecraft | `1.21.1` |
| NeoForge | `21.1.194` 或更高（开发与验证基线 `21.1.249`） |
| **Beyond Dimensions（超越维度）** | `0.7.30` 或更高 |
| **ProjectE（等价交换）** | `1.1.0` 或更高 |
| JEI（**可选**） | `19+`；若用较新的 JEI 构建，注意它自身可能要求更高的 NeoForge<br>（例如 JEI `19.44.0.401` 要求 NeoForge `21.1.238+`） |

**本模组不包含上述模组**，请自行下载后与本 jar 放进同一个 `mods/` 目录。
只放本模组会导致游戏拒绝加载并提示缺少依赖。

> 升级时请**先删掉旧的 `beyondemc-*.jar`** 再放新 jar —— 同一个 `modId` 出现两个 jar 会让游戏报
> "version differences that were not resolved"。仓库里的 `tools/install-to-mods.cmd` 会自动清旧版。

## 0.3 的主要变更：物化

### 新增：网络里的物品变成真实条目（"物化"）

网络已经学会、又买得起、且**没有真实库存**的物品，会在网络存储里生成**真实的存储条目**：

- 数量口径：**按 EMC 总额、各物品彼此独立、逐件向下取整** ——
  `数量 = floor(网络 EMC ÷ 该物品购买价)`。
  例：EMC = 100、钻石单价 50、泥土单价 1 ⇒ **钻石 2 个 + 泥土 100 个**。
- **取出即收缩**：兑换/取出后 EMC 减少，所有物化条目一起按新余额重算
  （EMC 降到 70 ⇒ 钻石 1 个 + 泥土 70 个）。
- **真实库存优先**：网络里真有某件物品的实体时，那件物品不会被物化（不会出现两行）。
- **取用一律收费**：不管从哪条路取（界面点击/吸附、网络接口按槽位、按标签抽取），
  都**先扣 EMC 再交付**；余额不够就**什么都不交付**（不交半份）。
  界面里的物化行点击后仍然"吸附到鼠标"，与 0.2 的手感一致。

### 新增：配置 `[materialize]`

`config/beyondemc-server.toml`：

```toml
[materialize]
materializeItems = true      # 总开关。false ⇒ 清空全部物化条目，回到 0.2 的行为
materializeMode = "STORAGE"  # STORAGE（默认，写进网络存储）/ LEDGER（未实现）/ OFF
maxMaterializedItems = 512   # 条目数上限，超出按"价格升序 + 注册名"确定性取前 N
```

关掉 `materializeItems` 就完全回到 0.2 的行为（客户端虚拟条目兜底），**不需要删存档**。

### 新增：命令

```
/beyondemc materialize list      # 列出当前网络的物化条目（数量、单价、EMC 余额）
/beyondemc materialize rebuild   # 立刻按当前 EMC 重算一遍
/beyondemc materialize clear     # 清空物化条目（EMC 不动）
```

### 0.3.1 相对 0.3.0 的差异

**只含自检与文档，不改任何游玩行为**：

- 自检从覆盖"按键抽取"扩到**全部三条 BD 抽取入口**（按键 / 按槽位 / 按标签），
  每条都带"外部抽取必被拒 + 物化层自用必放行"的正控 —— 物化组自检 22 → **26 项**；
- 修正 README 里 `NeoForge 21.1.234+` 的错误说明（配套 JEI 要求 `21.1.238+`，
  照原文安装会在模组加载阶段直接崩）。

## 安装

1. 安装 **NeoForge 21.1.194+**（推荐 `21.1.238+`，兼容较新的 JEI）
2. 把下面这些 jar 放进 `mods/`：
   - `beyondemc-1.21.1-neoforge-0.3.1.jar`（本 Release 的附件）
   - Beyond Dimensions
   - ProjectE
   - JEI（可选，想要配方填充就装）
3. 启动游戏，在 **Mods** 列表里应能看到 "Beyond EMC"
4. 进入维度网络界面，先**存入一件东西**（让网络学会它），物化条目就会出现

服务端同理；本模组是 **BOTH** 端，客户端也要装。

## 从 0.2.0 升级

- **直接替换 jar**。旧的 EMC 余额与学习集合**原样保留**，
  物化条目会在第一个触发点（存物品 / 开界面 / 兑换）之后按现有 EMC 自动生成。
- 用一个 0.2.0 时期建的世界首次进 0.3，日志里会出现一行
  `The following mods have version differences that were not resolved: beyondemc (version 0.2.0 -> 0.3.1)`。
  这是原版模组加载器的**存档模组版本核对**提示（存档里记的是 0.2.0），**属正常现象**，实测不崩、不影响数据。
- 不想要物化就 `materializeItems = false`，行为与 0.2 一致。

## 从 0.1.0 升级

跳过 0.2 的话，请先看 `docs/release-notes-v0.2.0.md` 里的**点击行为变化**
（左键 = 吸附到鼠标、Shift+左键 = 直接进背包）。

## ⚠️ 卸载 / 回退前必读

**移除本模组会让所有维度网络里的 EMC 归零。**

因为 EMC 是以自定义资源类型存在网络存储里的，超越维度在反序列化时对未注册类型会丢弃条目
—— 存档不会损坏，但那部分 EMC 会无声消失。**建议**卸载前先
`/beyondemc exchange <物品> <数量>` 把 EMC 换成物品取出。

**回退到 0.2.0 是安全的**（实测，见下）：拿 0.3 的存档去跑 0.2 的代码 ——

- **不崩**（服务端 `Done`，无异常）；
- **EMC 与学习集合完整无损**；
- 物化条目会被超越维度丢弃（日志里逐条 WARN）——这**不是价值损失**：
  EMC 池还在，0.2 会用它重新算出虚拟条目照常显示；升回 0.3 时也会按 EMC 重新物化。

## 已验证到什么程度

**自动自检**（每次启动都会跑，也会写进日志；游戏内 `/beyondemc selftest` 可手动触发）：
共 **54 项通过 + 4 项按端侧跳过，0 失败**，其中物化专项 26 项。

**人工实测**（2026-10-01，真实 EMC 表）已确认的核心事实：

- 直接解析存档：网络里确实有 **14 条** `beyondemc:stack_type/emc_item` 真实条目，
  EMC 池 3 066 234；其中 8 项的数量与购买价满足精确恒等式 `数量 = floor(EMC ÷ 单价)`，
  另外 6 项也都落在对应价格区间内 —— 口径正确；
- 14 条同类型条目**各自独立**存在（数量互不相同），没有被 `HashMap` 合并 —— 不塌缩；
- 网络接口取走物化物品时**确实扣 EMC**（日志逐笔：钻石 ×1 扣 8192、木棍 ×1 扣 4）；
- 客户端**不再注入虚拟条目**（由服务端真实持有）；
- 存档往返：客户端写入的 14 条，被另一个进程（专用服务器）**全部读回，0 解码错误**；
  服务器自动保存回写后再比对，**逐项完全相同**（写 → 读 → 再写闭环）；
- 回退演练：同一存档交给 0.2.0 → 启动成功、EMC 与学习集无损（见表）。

完整数据与复现命令：`docs/testing/phase8-materialize-report.md`。

**尚未覆盖**（会在后续版本补齐）：按标签抽取的收费侧、余额不足的拒绝实测、
多人并发兑换、第三方物流管道可见性、10 万件量级的性能。

## 排查问题

游戏内运行：

```
/beyondemc selftest
```

它会逐项检查存储层、折算钩子、读档守卫、兑换服务、策略配置、**Mixin 目标存活性**、
网络接口兑换、鼠标吸附、JEI 可用量、**物化**，并在日志里给出结论与原因。
日志里带 `[BeyondEMC]` 前缀的行都是有意的诊断输出。

物化相关的排查起点：

| 现象 | 先看 |
|---|---|
| 界面里没有物化行 | 日志里 `EMC 表已就绪` 是否出现；`/beyondemc materialize list` 是否有条目 |
| 条目数量不对 | `/beyondemc materialize rebuild` 强制重算一次 |
| 只想关掉它 | `config/beyondemc-server.toml` → `materializeItems = false` |
| 升级 BD 后功能无声消失 | 日志里 `Mixin 目标存活性` 那一行（失配会逐条列出失效目标） |
